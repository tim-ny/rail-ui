Select

<x-select />

Custom dropdown with single/multiple selection, search, icons, images, keyboard navigation, and flexible option objects.

On this page
Usage Props Option format Basic select With icons Multiple selection With descriptions

Usage

Props

Prop Type / Options Default Description
options array [] Array of strings or ['value', 'label', 'icon', 'image', 'description', 'disabled'] objects.
value string|array null Initially selected value(s).
label string null Label rendered above the select.
placeholder string Select... Placeholder text when nothing is selected.
multiple bool false Allow selecting multiple options.
searchable bool false Adds a search input to filter options.
clearable bool false Shows an X button to clear the selection.
size xs, sm, md, lg, xl md Select input scale.
color primary, danger, success, warning, neutral primary Focus ring accent color.
disabled bool false Disables the select.
wireModel string null Livewire wire:model binding.
unstyled bool false Strip all Aegis classes.
