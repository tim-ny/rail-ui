Checkbox

<x-checkbox />

Inline-label checkbox with radius levels, sizes, indeterminate and block/card mode.

On this page
Usage Props Colors & sizes Radius levels States & feedback Block / card mode

Usage

Props

Prop Type / Options Default Description
label string null Text rendered to the right of the control.
checked bool false Initial checked state.
indeterminate bool false Renders the dash state (via Alpine).
value string null Value submitted with the form.
size xs, sm, md, lg, xl md Box scale.
color primary, danger, success, warning, neutral primary Checked color.
radius none, xs, sm, md, lg, full sm Corner rounding of the box.
block bool false Card mode — label wraps arbitrary slot content.
hint / error / valid / required … — Validation + feedback (see Form Field).
readonly / disabled bool false Native states with themed styling.
wireModel / wireModelModifier string null Livewire binding.
unstyled bool false Removes wrapper styles.
