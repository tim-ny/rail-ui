Theming & Customization

Every visual value is a token. Change the tokens, rebrand the library.

Design tokens

Tokens are declared in the package CSS under @theme and exposed as --ui-* custom properties. They group into five families:

Family Examples
Colors --ui-color-primary, --ui-color-danger, --ui-color-success, --ui-color-warning, --ui-color-neutral (+ -soft, -border variants)
Radius --ui-radius-none, -xs, -sm, -md, -lg, -full
Type --ui-font-sans, --ui-font-size-xs…-xl
Spacing --ui-space-xs…-xl — used for padding and gaps
Controls --ui-input-height-xs…-xl, --ui-icon-size-xs…-xl, --ui-transition-fast, --ui-shadow-lg

Override tokens in your app

Add rules to your app stylesheet. Any element that references the token picks up the new value automatically — no component changes required.

Component defaults

Set app-wide defaults for any prop in config/rail-ui.php. Resolution order is inline prop > config default > package default.
