Form Field

<x-form-field />

A wrapper that groups a label, control and feedback into one consistent unit.

Usage

Props

Prop Type Default Description
label string null Field label.
hint string null Helper text.
error string null Error message (with role="alert").
valid bool false Success state.
required bool false Renders the required asterisk.
readonly bool false Readonly state.
id / name string null Wiring for the control.
unstyled bool false Removes wrapper styles.
