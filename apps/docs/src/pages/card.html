Card

<x-card />

Flexible content container with slots for media, header, body, footer, and avatar overlays.

Usage

Props

Prop Type / Options Default Description
padding none, sm, md, lg md Inner body padding.
shadow none, sm, md, lg sm Box shadow level.
border bool true Shows a 1px border.
href string null Makes the entire card a link.
overflow bool false Hides overflow (for full-bleed media).
unstyled bool false Removes all wrapper styles.

Slots

Slot Description
default Main card content (description, text, etc).
media Image or video rendered at the top of the card.
header Title, subtitle, or heading content.
footer Actions, buttons, or links at the bottom.
avatar Overlapping avatar for profile cards.
