Dropdown

<x-dropdown />

Contextual menus with items, headers, dividers, checkboxes, radio groups and nested submenus — powered by Alpine.js, zero JavaScript required.

On this page
Usage Props — x-dropdown Sub-components Basic menu With checkboxes Danger item & disabled item Submenu

Usage

Props — x-dropdown

Prop Type / Options Default Description
trigger string Open Trigger button label (used when no $trigger slot is provided).
align left, right, center left Horizontal alignment of the menu relative to the trigger.
size sm, md, lg md Menu and item padding scale.
variant solid, soft, outline, ghost solid Trigger button style.
color primary, neutral, danger, success, warning primary Trigger button accent color.
unstyled bool false Strip all Aegis classes from the trigger and menu wrapper.

Sub-components

Tag Description
<x-dropdown-item> A clickable link or button row. Accepts href, icon, shortcut, disabled, and danger props.
<x-dropdown-header> A non-interactive label that groups items visually.
<x-dropdown-divider> A horizontal rule separating groups of items.
<x-dropdown-checkbox> A toggle item with a checkmark. Accepts label, name, checked, and wire:model.
<x-dropdown-submenu> A nested flyout menu. Pass the nested items as the default slot.
