Banner

<x-banner />

Top-of-page announcement bar with transitions, dismiss, auto-hide and action slots.

Usage

Props

Prop Type / Options Default Description
title string null Bold heading text.
icon string null Tabler icon name rendered before the title.
href string null Makes the entire banner a link. Omit for static text.
closable bool true Shows a dismiss (×) button.
showAfter int (ms) 300 Delay before the banner animates in.
autoHide int (ms) 0 Auto-dismiss after N ms. 0 = stays visible.
fixed bool true Fixed to the top of the viewport.
variant solid, outline, soft, ghost soft Visual style.
size sm, md, lg md Padding and font scale.
color primary, danger, success, warning, neutral primary Color theme.
unstyled bool false Removes all wrapper styles.

Slots

Slot Description
default Description text shown after the title.
action CTA button or link shown on the right side of the content.

Variants

Soft (default) This is a soft banner with primary color.
Solid Solid background with contrasting text.
Outline Border bottom with themed color.
Ghost Transparent background, themed text.

Sizes

Small Compact banner for tight spaces.
Medium (default) Standard banner size.
Large Larger banner for important announcements.
