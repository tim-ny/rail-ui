About Aegis UI

The story, the stack and the principles behind the library.

What it is

Aegis UI is a component library for Laravel built as a Composer package. It ships pre-styled Blade components driven entirely by CSS custom properties (--ui-*), so the look is yours to own from day one — every color, radius, spacing value and state can be overridden in a single token layer.

Why it exists

Most component kits either lock you into a design, or force you to write every class by hand. Aegis UI sits in the middle: it ships a complete, accessible, tested design system as plain Blade + CSS, but keeps the design tokens as the only source of truth for visuals.

The stack

  • Laravel 13 — Blade components, config and service providers.
  • Livewire 4 — optional wire:model support via hidden inputs.
  • Alpine.js 3 — popovers, calendars, accordions and toggle state.
  • Tailwind CSS 4 — @theme tokens power the package CSS.
  • Tabler Icons — iconography through <x-icon>.

Design principles

  • Token-driven, not hardcoded. No hex values live in component styles — only var(--ui-…).
  • BEM class names. ui-btn--solid, ui-datepicker__cell--selected… predictable and tree-shakeable.
  • Configurable defaults. Inline props beat config/aegis-ui.php defaults, which beat package defaults.
  • Unstyled when you need it. An unstyled prop strips wrapper chrome so you own the layout.
