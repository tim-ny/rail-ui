Accordion

<x-accordion />

Collapsible panels with single or multiple open modes.

Usage

Props

Prop Type / Options Default Description
multiple bool false Allow several panels open at once.
variant outline, soft, ghost, flush outline Container style.
size sm, md, lg md Item padding scale.
color primary, danger, success, warning, neutral neutral Accent color.
defaultOpen string / array null Item id(s) open on load.
block / unstyled bool false Full-width / unwrapped.
<x-accordion-item /> props
title string null Header label (or pass a $trigger slot).
leadingIcon string null Icon before the title.
disabled bool false Item cannot be opened.
id string auto Slug-generated by default.
