Alert

<x-alert />

Contextual feedback with auto-resolved icons and an optional dismiss button.

Usage

Props

Prop Type / Options Default Description
variant soft, outline, solid, ghost soft Visual style.
size sm, md, lg md Scale.
color primary, danger, success, warning, neutral primary Theme. Picks the fallback icon & ARIA role.
title string null Bold title line.
icon string auto Tabler icon name; "none" hides the icon.
dismissible bool false Shows the × dismiss button.
block bool false Full-width alert.
unstyled bool false Removes wrapper styles.
