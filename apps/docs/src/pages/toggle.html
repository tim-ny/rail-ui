Toggle

<x-toggle />

On/off switch with sizes, colors, labels, and accessible role="switch".

Usage

Props

Prop Type / Options Default Description
label string null Label text next to the switch.
checked bool false Initial on/off state.
size xs, sm, md, lg, xl md Switch track and knob scale.
color primary, danger, success, warning, neutral primary Accent color when toggled on.
disabled bool false Disables the toggle.
required bool false Shows required indicator and sets aria-required.
hint string null Hint text below the toggle.
error string null Error message (overrides hint).
wireModel string null Livewire wire:model binding.
unstyled bool false Strip all Aegis classes.
