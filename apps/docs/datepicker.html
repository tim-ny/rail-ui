Date Picker

<x-datepicker />

Alpine-powered calendar with single, range, multiple, month and year selection, presets, week numbers, disabled dates and multi-month views.

Usage

Modes & formats

The mode prop drives granularity and selection type.

Mode Granularity Selection Description
single day single One date.
range day range Start + end date.
multiple day multiple Any set of dates.
month month single One month.
month-range month range Start + end month.
year year single One year.
year-range year range Start + end year.

Props

Prop Type / Options Default Description
mode single, range, multiple, month, month-range, year, year-range single Selection behaviour.
format M d, Y · MM-DD-YYYY · DD-MM-YYYY · YYYY-MM-DD · D d M, Y · MMMM d, Y M d, Y Display format.
size xs, sm, md, lg, xl md Trigger height.
color primary, danger, success, warning, neutral primary Focus / selection color.
value string / array null Initial value. Ranges accept "A - B", arrays or objects.
label / hint / error / valid … — Form-field text + validation state.
required / readonly / disabled bool false Field states.
weekNumbers bool false Show ISO week numbers in the day grid.
presets bool / array false true builds server defaults; an array passes your own shortcuts.
disabledDates array [] ISO date keys (Y-m-d) to disable.
min / max string null Inclusive ISO bounds.
firstDayOfWeek 0, 1 0 Week starts on Sunday or Monday.
numberOfMonths int 1 Months shown side by side.
fixedWeeks bool false Always show 6-week grid.
clearable bool false Shows a clear button in the trigger.
viewControl / monthControls / yearControls bool true Toggle view drilling and nav arrows.
placeholder / id / name string — Native input attributes.
wireModel string null Livewire property bound via a hidden input.
unstyled bool false Removes wrapper styles.
