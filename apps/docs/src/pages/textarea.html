Textarea

<x-textarea />

Multi-line text input with variants, sizes, auto-resize, character count and validation.

Usage

Props

Prop Type / Options Default Description
rows int 3 HTML rows attribute. Controls initial visible height.
maxlength int null Maximum character count. Shows a live counter when set.
autoResize bool false Textarea grows/shrinks automatically with content.
variant outline, soft, subtle, ghost, none outline Field visual style.
size xs, sm, md, lg, xl md Height scale.
color primary, danger, success, warning, neutral primary Focus/theme color.
label / hint / error string null Form-field text (see Form Field).
valid bool false Shows the success state.
required / readonly / disabled bool false Native states with themed styling.
loading bool false Shows a spinner overlay on the textarea.
block bool false Full-width control.
placeholder / autocomplete / autofocus string / bool — Passed to the native textarea.
wireModel / wireModelModifier string null Livewire binding.
unstyled bool false Removes wrapper + field styles.
