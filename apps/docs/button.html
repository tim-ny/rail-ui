Button

<x-button />

Triggers an action. Renders a <button> or an <a>.

On this page
Usage Props Variants & colors Sizes Icons, links & states

Usage

Props

Prop Type / Options Default Description
variant solid, soft, outline, ghost solid Visual style of the button.
size xs, sm, md, lg, xl md Height scale.
color primary, danger, success, warning, neutral primary Color theme.
as button, a button Root element override.
href string null Renders an anchor when set.
target string null Link target.
external bool false Shortcut for target="_blank".
type button, submit, reset button Native type when rendered as <button>.
disabled bool false Disables pointer events and sets aria-disabled.
loading bool false Replaces content with the spinner + loading indicator.
block bool false Full-width button.
leadingIcon string null Tabler icon name rendered before the label.
trailingIcon string null Tabler icon name rendered after the label.
wireModel string null Binds a Livewire property.
unstyled bool false Removes all wrapper styles.
