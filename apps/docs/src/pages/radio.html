Radio Group

<x-radio-group />

Card-style radio group with sizes, colors, descriptions, and Alpine.js-powered selection state.

Usage

Props — x-radio-group

Prop Type / Options Default Description
name string auto Radio group name attribute. Auto-generated from id if not set.
value string null Initially selected value.
label string null Group label rendered above the options.
required bool false Shows required indicator and sets aria-required.
size xs, sm, md, lg, xl md Radio card and circle scale.
color primary, danger, success, warning, neutral primary Accent color for selected state.
disabled bool false Disables all radios in the group.
hint string null Hint text below the group.
error string null Error message (overrides hint).
wireModel string null Livewire wire:model binding.
unstyled bool false Strip all Aegis classes.

Props — x-radio

Prop Type / Options Default Description
value string null Value submitted with the form.
label string null Primary label text.
description string null Secondary text below the label.
disabled bool false Disables this individual radio.
unstyled bool false Strip all Aegis classes.
